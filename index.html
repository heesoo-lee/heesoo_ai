1. 장애 대응 및 원인 분석

  • TP 서버 Boot 실패 분석: 부팅 로그, dmesg, journalctl 확인
  • Core Dump 분석: gdb를 이용한 백트레이스 수집
  • ULOG, SLOG, TMLOG 로그 확인: 로그 파싱 및 상관관계 분석
  • 서비스 응답 지연 및 Timeout 분석: 네트워크/프로세스/DB 지연 원인 추적

2. 서비스 배포 및 운영

  • 신규 서비스 등록: 서비스 메타데이터 및 모니터링 설정
  • 서버 추가: 롤링 프로비저닝과 LB 등록 절차
  • Binary 배포: 안전한 롤백을 가진 배포 파이프라인

3. 성능 관리

  • CPU 사용률 모니터링: 경고 임계치 정의
  • Memory 사용률 추적: 누수 감지
  • 프로세스 상태 확인: 주요 데몬 헬스체크
  • 응답시간 모니터링: SLO/SLA 기반 알림
  • 병목 분석: flamegraph, 프로파일링 도구 활용

4. 시스템 점검

  • 디스크 용량 확인: 용량 임계치 및 자동 경보
  • 로그 정리: 보관 정책 및 압축/삭제
  • Backup 확인: 복원 테스트 포함
  • Patch 적용: 검증과 롤백 계획
  • 재기동 작업: 안전한 재기동 절차 문서화

5. 운영 자동화

Shell Script를 이용한 샘플 자동화 스크립트를 제공합니다. (scripts 디렉터리)

  • 배포 자동화: deploy.sh
  • 백업 자동화: backup.sh
  • 로그 삭제: log_cleanup.sh
  • 상태 점검: check_status.sh
  • 재기동 자동화: restart.sh

6. 장애 예방

  • 모니터링: 지표 + 로그 융합 알람
  • 로그 분석: 주기적 패턴 탐지 및 인사이트
  • 용량 관리: 예측 기반 확장 계획
  • 패치 적용: 취약점 기준 우선순위
  • 취약점 조치: CVE 기반 대응 프로세스

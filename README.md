# TP Middleware Operations

TP 미들웨어 운영 업무를 소개하는 정적 홈페이지입니다.

## 주요 업무
- 장애 대응 및 원인 분석
- 서비스 배포 및 운영
- 성능 관리
- 시스템 점검
- 운영 자동화
- 장애 예방

## 기술
HTML / CSS / JavaScript / GitHub / GitHub Pages / AI Vibe Coding

## GitHub Pages
`master` 브랜치에 push하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.

> 실제 내부 시스템명, 서버명, IP, 계정, 고객정보 및 보안정보는 포함하지 않은 업무 소개용 페이지입니다.
